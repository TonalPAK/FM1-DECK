# ADR-0005: The name FM1 DECK, package io.github.fm1deck, no M-VAVE branding

Status: accepted (2026-10-12).

The name is neutral: it is clearly about the FM-1, but does not pretend to be an M-VAVE product. No M-VAVE logos,
fonts or enclosure look are used. `applicationId = io.github.fm1deck` (never changes after the first release:
a new id means a new install).
